2. **Panel-local sizing**, potentially including that initialization. The absolute, auto-height panel is a flex column; swatches use a fixed four-column grid; slider/actions use flex. 3. **Style/layout outside the panel.** The document-root metadata permits this, not proves it. The room layer is fixed/inset; the panel is absolute without explicit containment. Opening starts the START outro while adding the panel. Global html[data-intro] rules affect room/page styling, but Lantern focus does not toggle that attribute.
